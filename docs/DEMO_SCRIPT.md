# Suggested 80-second demonstration

This is the historical rehearsal outline. The final published contest demo is
[available on X](https://x.com/gptnius/status/2120259388568961305); the current
feature/status index is the [roadmap](ROADMAP.md). The outline below retains its
original scope and is not the final film script. Use a clean synthetic workspace
when rehearsing it.

0–12 seconds: Open the native CRM pane in Hermes Desktop, with both plugin components enabled in a disposable profile. Explain that the same profile-local CRM is used by the pane and the existing Hermes agent. Focus or hover a dashboard stage for value, deal count and unique-contact details, then click to open its contact report. Show the active Stage filter; Contact type is a separate category.

12–28 seconds: Ask the agent to create Demo Buyer at buyer@example.com and a $12,000 qualified opportunity. Show the new contact and deal in the workspace. Confirm the amount displays as $12,000 rather than cents.

28–43 seconds: Open the contact detail, add an internal follow-up with an explicit date and timezone, then show its task and activity history.

43–58 seconds: Ask the existing Hermes agent to move the deal to proposal using its latest version. Refresh the UI and show the pipeline/weighted forecast change.

58–73 seconds: Explicitly schedule the follow-up as a one-shot local Hermes reminder. Show the returned job ID and honest scheduled status. Registration alone does not prove execution. If showing the verified scheduler run and saved local output, label its model endpoint as deterministic and loopback-only. Do not imply that a real model or a visible Desktop notification was tested.

73–80 seconds: Show the portability/test summary: SQLite default, explicit PostgreSQL, active-profile isolation, local-first operation. Finish with a clear prototype label and repository link only once the repository has been reviewed and published.

Do not display credentials, home-directory paths, real contacts or another CRM. Do not post this demonstration or submit contest links without authorization.
